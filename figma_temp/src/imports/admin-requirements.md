# 管理画面：要件

１、ログイン画面
　・管理画面＞アカウント管理の情報でログインできる
　・ログイン成功後にダッシュボードに遷移

２、ダッシュボード

　・集計機能あり（新規会員数、アクティブ会員）
　・予約一覧表示（予約状況、支払状況）
　・お問い合わせ一覧表示
　・管理メニュー（会員管理、予約管理、請求管理、問合せ管理、予約枠管理）

３、左サイドメニュー
　・ダッシュボード
　・集計（KPI）
　・会員管理
　・予約管理
　・請求管理
　・お問合せ管理
　・お知らせ管理
　・固定ページ管理
　・マスタ管理
　　・予約枠管理
　　・体験オプション管理
　　・キャンセルポリシー管理
　　・よくある質問管理
　・アカウント管理
　・マニュアル管理

４、集計（KPI）
　・予約状況のKPIを集計し、より効率的な売り上げにつながる集計の表示
　・年間や月の売り上げ、リピーター率、利用後のアンケート集計など
　・体験プログラムの効果測定ができるようにする（年、月、会員ステータス別の人気など）

５、会員管理
　※既存のメンバー管理を流用し、「会員管理」に文言変更する
　※フロント側＞本会員登録の項目を反映する

６、予約管理
　・予約情報を管理する
　・電話での新規予約対応もできるようにしておく（会員未登録の場合も想定）
　・予約状況、支払状況なども一覧で見れるようにする
　・キャンセルの場合、キャンセルポリシーにそって支払いが発生する

７、請求管理
　・支払状況をもとに年間や月の売り上げを集計し表示
　・支払状況一覧を表示

8、お問合せ管理
　・フロント側＞お問い合わせ画面からの問い合わせ内容を一覧表示
　・各問合せの対応状況を見えるようにする

９、お知らせ管理
　・フロント側＞トップページに表示するお知らせ一覧の管理
　・フロント側＞マイページに表示するお知らせ一覧の管理

10、固定ページ管理
　・フロント側＞施設紹介、フロント側＞周辺情報、フロント側＞利用規約、フロント側＞個人情報取り扱いなどの画面を管理する

11、マスタ管理
　11-1、予約枠管理
　　・Googleカレンダーと連携して、予約可能な枠を設定
　　・手動でも予約可能日を調整できるようにする
　　・予約可能期間を設定する
　11-2、体験オプション管理
　　・フロント側＞体験プログラム画面に表示する各体験オプションの情報を新規登録、編集、削除（論理削除）する
　　・各体験プログラムの人気順を集計できるようにする
　11-3、キャンセルポリシー管理
　　・キャンセルポリシーを設定。ここで設定したキャンセルポリシーによって、予約キャンセル時の支払い設定をする
　11-4、よくある質問管理
　　・フロント側＞よくある質問画面に表示するよくある質問の新規登録、編集、削除（論理削除）する

12、アカウント管理
　※既存のアカウント管理を流用する

13、マニュアル管理
　※マークダウン形式でフロント側と管理画面側のマニュアルを作成・編集ができるようにする
