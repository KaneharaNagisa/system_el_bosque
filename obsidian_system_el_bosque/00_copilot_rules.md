# Copilot共通ルール

## 回答方針

- 日本語で回答してください。
- ファイル全体のコードは出力せず、**変更が必要な箇所のみ（差分）** を提示してください。
- 仕様にない機能を勝手に追加しないでください。
- 不要なリファクタリングや、関係のないコードの書き換えは禁止です。
- 最初にコードを変更せず、変更方針と変更範囲を提示し、問題ないことを質問してください。

## 実装・技術制約

- 変更は最小限にしてください。 
- 仕様にない機能を勝手に追加しないでください。追加する際は必要かを質問してください。
- 不明点や仕様の矛盾があれば、コードを書く前に必ず質問してください。
- 既存の命名規則やディレクトリ構造を最優先してください。
- anyの使用は避けてください。
- 大幅な変更が必要な場合は実行する前に、設計方針を説明し、実行の有無を質問してください。
- なるべくクレジットを節約できる内容を提案してください。
- コマンド実行など依頼した方がクレジットを節約できる場合は、ユーザーに依頼してください。

## 禁止事項 

- 不要な大規模リファクタリングは禁止です。 
- 勝手なライブラリ追加は禁止です。 
- ファイル構成の大幅変更は禁止です。 
- 関係ないコード整形は禁止です。


## 出力形式 

基本的に以下の順番で回答してください。 

1. 変更方針 
2. 変更対象ファイル 
3. 変更箇所 
4. 確認ポイント
