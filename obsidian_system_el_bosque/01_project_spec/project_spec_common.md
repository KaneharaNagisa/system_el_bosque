# プロジェクト確定仕様書

## プロジェクト概要

- アプリ名: エルボスケ予約システム
- 目的: エルボスケというシステム依頼者が所有しているログハウスの一棟貸しの予約システムを構築

## 技術スタック

- フロントエンド: React、Inertia.js
- バックエンド: Laravel
- DB / 環境: Docker (コンテナ名: system_el_bosque)

## 絶対に崩してはいけない重要仕様

Reactは「Inertia.js」を利用してLaravelとつなげてください。

01_project_spec/admin/project_spec_common_enduser

### 管理画面：要件

01_project_spec/admin/project_spec_common_admin

## 禁止事項

### システム全体共通

- プロジェクト名\figma_temp内のソースは変更しないでください。

### エンドユーザー画面

#### figmaでエンドユーザー側画面のデザイン更新の場合

- figmaでエンドユーザー側画面のデザイン更新の場合はsystem_el_bosque\figma_temp\src内のReactソース（色味、フォント、文字色、レイアウト）をプロジェクト名\src内に反映してください。エンドユーザー側のレスポンシブ対応（ブレイクポイント）も反映してください。
-  figmaでエンドユーザー側画面のデザイン更新の場合は現状のDBからデータ取得している箇所はコンテンツ内容を変更しないでください。
-  figmaでエンドユーザー側画面のデザイン更新の場合は理画面側のソースは変更しないでください。


### 管理画面

- 管理画面はPCでのみ操作のためレスポンシブ対応は不要です。
