２、予約フォーム（宿泊日程の選択）

- 予約可否の判定は必ず管理画面＞マスタ管理＞予約枠管理（`availabilities`テーブル）のデータを正としてください。
- 日付ごとの判定ルール（優先順）
  1.  `availabilities`テーブルに明示的な登録がある場合は、その`status`に従う（`available`=空きあり、`booked`=予約済み、`cleaning`=清掃準備中、`closed`=予約不可、`manual_blocked`=予約不可、`offseason`=休業期間）。
  2.  登録が無い日付は、営業期間（毎年3月〜12月）内かつ本日以降であれば「空きあり」とみなす。
  3.  登録が無い日付でも、火・水・木は定休日として「予約不可」とみなす。
  4.  営業期間外、または本日より前の日付は「休業期間」として選択不可にする。
- 上記の判定は、日程選択欄（チェックイン・チェックアウトの入力カレンダー）と、その下に表示される空き状況カレンダーの両方で一致させること。管理画面で「予約不可」に設定した日付は、どちらのカレンダーからも選択できないようにする。
