# Copilotの過去のミス・注意点メモ

※Copilotが仕様を間違えるたびに、ここに1〜2行で書き足していきます。

- [ ] APIのレスポンス形式を勝手に `{ data: ... }` に変えようとした。正しくは `{ success: true, result: ... }`。
- [ ] 日本語のエラー文言を勝手に英語に変えてしまった。
- [ ] 1～５名は一棟貸しの料金が変わらないのに、１～５名の人数によって料金を加算してしまった。
- [ ] Googleカレンダーの予定ありなしを管理画面＞マスタ管理＞予定枠管理に反映してほしいと依頼したときに、Googleカレンダーの予定名なども反映しようとした。
